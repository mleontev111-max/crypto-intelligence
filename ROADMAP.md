# ROADMAP

## Phase 0 — Foundation

Define continuity protocol, project constitution, data architecture, point-in-time requirements, BTC MVP, forecast ledger, model lifecycle, canonical schemas, and data-source registry.

Exit gate: a new contributor can understand the project from GitHub alone; canonical schemas are committed; historical knowledge/forecast immutability rules are explicit; no live ingestion has started prematurely.

## Phase 1 — Market Observatory

BTC only. Collect and normalize core market, derivatives, macro, basic on-chain, and curated news/event data. Build monitoring and data-quality dashboards. No investment recommendations.

Exit gate: stable collection with observable gaps/quality metrics and reproducible snapshots.

## Phase 2 — Forecast Ledger

Add rule-based probabilistic forecasts for 4h/24h/7d, immutable forecast records, and automatic outcome closure/evaluation.

Exit gate: enough closed forecasts exist to evaluate calibration and baseline performance.

## Phase 3 — Quant Models

Add simple baselines, logistic regression, tree models, calibration, walk-forward evaluation, and regime-aware analysis.

Exit gate: at least one candidate beats predefined simple baselines out-of-sample without unacceptable risk/instability.

## Phase 4 — AI Analyst

Use LLMs for event extraction, context, contradiction analysis, scenario narratives, and briefings. Numerical probabilities remain owned by quant models.

## Phase 5 — Paper Portfolio & Risk

Add virtual portfolio, transaction-cost/slippage simulation, sizing, risk limits, and benchmark comparison. No real money.

## Phase 6 — Controlled Model Learning

Automate challenger training, shadow forecasts, drift detection, model comparison, and governed promotion/rejection.

Any later consideration of live execution requires a new explicit phase, legal/risk review, owner approval, and a separate safety checkpoint.
